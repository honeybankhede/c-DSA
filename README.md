## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Compile a C++ file:

   ```bash
   g++ filename.cpp -o output
   ```

4. Run the program:

   ```bash
   ./output
   ```

   On Windows PowerShell:

   ```powershell
   .\output.exe
   ```
